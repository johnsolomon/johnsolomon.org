Help

    
Where your settings live

    

      
On the mouse
One active setup: buttons, HyperShift, sensitivity, lighting and power. It works on any computer with no software, including the hospital PC.

      
Layouts, in this browser
Named copies like Work and MapleStory. They do nothing until you load one onto the mouse.

      
History, in this browser
Automatic copies of the mouse from before each change. Download a full backup to keep them.

    

    
How your setup is protected

    

      
Connecting never changes the mouse
Synapse can push a blank setup onto a mouse on a new computer, after an update or when cloud sync fails. This page only writes when you change something.

      
Outside changes are caught
If Synapse, another app, another computer or a reset changed the mouse, you'll see a warning with a one-click restore.

      
Every change is saved permanently and checked
Changes go to the mouse's permanent memory and are read back. If the mouse sleeps or unplugs halfway, you can roll back.

      
Edits follow the profile button
Changes always go to the on-board slot the mouse is using.

      
Use one editor at a time
Close Synapse, OpenSnek and Naga Studio while this page is open.

    

    
Razer terms

    

      
Synapse profile
A setup kept in Razer's Synapse app. Same idea as a layout here.

      
On-board profile
A setup stored inside the mouse. The V3 Pro has five slots, but only Synapse can create extra ones; normally the mouse uses slot 1.

      
Profile light
The light under the mouse shows the slot:1 white2 red3 green4 blue5 cyan.

      
HyperShift
A Shift key for the mouse. Hold the HyperShift button (the pinky button, from the factory) and the other buttons do their second job.

      
DPI
Sensitivity: how far the pointer moves per inch of mouse movement.

      
Chroma
Razer's name for the lights: scroll wheel, logo and side plate.

      
Turbo
Holding the button repeats its action, up to 20 times a second.

      
Macros
Typing text with one button. Not possible here yet.
